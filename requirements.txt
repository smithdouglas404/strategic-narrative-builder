# Strategic Narrative Builder 2.0 runs on the Python standard library.
# No packages are required for local use.
#
# Optional: install `cryptography` to encrypt secrets (SMTP password and AI
# provider API keys) at rest on non-Windows hosts. Without it the app still
# runs, but those secrets are stored in plaintext.
#
#   pip install cryptography
#
# cryptography>=42
#
# Optional: install `python-pptx` and `Pillow` to enable the C-level deck
# export. Without them /api/value-cases/<id>/c-level-deck.pptx returns
# "No module named 'pptx'"; the rest of the app is unaffected.
#
#   pip install python-pptx Pillow
#
# python-pptx>=0.6
# Pillow>=10
#
# The PDF variant of that export additionally needs LibreOffice (`soffice`)
# or PowerPoint on the host; it is a host package, not a pip install.
